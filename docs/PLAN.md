# 捷運擠車廂 H5 小遊戲｜專案規劃

Nov 10, 2026 · @Chia

## 專案概要

《門要關了！》是一款直向手機 H5 小遊戲：在車門關閉前，把月台上的乘客往車廂裡塞，塞得越多、越有秩序分數越高。一局約 2–3 分鐘，用 irasutoya 插圖營造可愛又有點崩潰的通勤感。

| 項目 | 規劃 |
| --- | --- |
| 類型 | 物理堆疆＋時間壓力的休閒遊戲 |
| 平台 | 手機瀏覽器為主（直向），桌機也能玩 |
| 操作 | 單指拖曳／點擊，無需教學就能上手 |
| 目標玩家 | 通勤族、學生，在等車或通勤時玩幾局 |
| 一局時長 | 6–8 站，約 2–3 分鐘 |
| 部署 | GitHub Pages，免費、無廣告、無課金 |
| 開發方式 | 在 Claude Code 實作，本文件作為規格書 |

## 核心玩法

每一站是一個回合：車門打開 10 秒，玩家把月台上的乘客拖進車廂，車門關閉時結算。車廂是橫向剖面畫面，乘客是有物理碰撞的圓角圖塊，會互相推擠。

**操作**

- 拖曳月台上的乘客，放開後把他「推」進車廂（用力滑越快，推得越深）
- 點車廂內的乘客：觸發各自的小動作（背包移到胸前、收起手機、往裡面移動）
- 一站最多可用 1 次「請往車廂內移動」廣播：整廂乘客往內側挤一點

**規則與結算**

- 車門關閉時，身體有一半以上在車廂內 = 上車成功
- 卡在門線上 = 「夹到了」：車門重開，扣滿意度並加 3 秒延誤
- 沒上車的乘客留在月台，下一站開始前會生氣，扣滿意度
- 到站時會有乘客下車，負責空出位置，空位變成下一站的空間

**計分**

| 事件 | 分數 |
| --- | --- |
| 每位乘客成功上車 | +100 |
| 一站全員上車 | +500 且連擊倍率 +1 |
| 特殊乘客到達指定位置（例：長者到博愛座） | +300 |
| 夹到門 | −200，連擊歸零 |
| 乘客被擠到超過壓力上限 | −150 |

**遊戲結束**：跑完整條路線的站數，或「乘客滿意度」歸零。結算畫面給一個會心一笑的稱號，例如「沙丁魚職人」、「博愛座守護者」，方便截圖分享。

## 關卡與進程

一局 = 一條路線，難度隨站數往「轉乘大站」爬升，尖峰後稍微放鬆，節奏簡單好調。路線用虛構的「北城捷運」，站名可以是令人會心的仑仑版（待決定，見文末）。

## 美術與音效素材清單

人物用 irasutoya，場景與 UI 優先用程式畫（簡單色塊＋圓角），AI 只用來補 irasutoya 沒有的東西。irasutoya 插圖控制在 20 張以內，就算未來加廣告也不用重做（原因見下一節）。

| 素材 | 來源 | irasutoya 搜尋關鍵字 | 張數 |
| --- | --- | --- | --- |
| 上班族（男、女） | irasutoya | 会社員、通勤 | 2 |
| 學生 | irasutoya | 学生、制服 | 1–2 |
| 背包客（背後／胸前兩種） | irasutoya＋加工 | リュック、バックパック | 1–2 |
| 低頭族 | irasutoya | スマホ、歩きスマホ | 1 |
| 長者 | irasutoya | お年寄り、老人 | 1–2 |
| 孕婦／抱嬰兒 | irasutoya | 妊婦、抱っこ | 1–2 |
| 大行李箱 | irasutoya | スーツケース | 1 |
| 結算表情（開心／崩潰） | irasutoya | 満員電車、表情 | 2–3 |
| 車廂剖面、月台、車門 | 程式繪製 | — | 0 |
| 按鈕、計時條、滿意度條 | 程式繪製 | — | 0 |

**素材處理規格**

- 一律轉成透明 PNG，長邊縮到 256 px，用 TexturePacker 或 free-tex-packer 打成一張 sprite atlas
- 物理碰撞範圍用簡化形狀（膠囊形），不照圖片輪廓算
- 每張圖在 `assets/CREDITS.md` 記下來源網址、是否加工、是否 AI 生成

**AI 補圖的做法**：prompt 描述風格特徵（扁平、粗輪廓線、柔和粉彩、簡單五官）即可，不要要求「照 irasutoya 的某張圖畫」或貼圖去仿製，避免做出看起來像官方素材、實際上不是的圖。

## 技術架構與專案結構

用 Phaser（內建 Matter.js 物理）＋ TypeScript ＋ Vite，打包成純靜態檔案，完全不需要後端，剛好符合 GitHub Pages。

| 項目 | 選擇 | 理由 |
| --- | --- | --- |
| 遊戲引擎 | Phaser（當下最新穩定版） | 場景管理、輸入、資源載入、音效全包，文件與範例多 |
| 物理 | Phaser 內建的 Matter.js | 乘客互相推擠、堆疊的手感就靠它 |
| 語言 | TypeScript | 乘客類型、關卡設定有型別，Claude Code 修改時比較不易出錯 |
| 建置工具 | Vite | 開發伺服器快，輸出靜態檔，設定 `base` 就能上 Pages |
| 儲存 | localStorage | 最高分、音量設定，第一版不做線上排行榜 |
| 畫面 | 設計尺寸 720×1280，Scale.FIT 置中 | 直向手機為主，桌機上兩側留白 |

**目錄結構**

```text
mrt-squeeze/
├─ index.html
├─ vite.config.ts            # base: '/mrt-squeeze/'
├─ public/
│  └─ assets/
│     ├─ atlas/passengers.png + .json
│     ├─ audio/
│     └─ CREDITS.md
├─ src/
│  ├─ main.ts               # Phaser 設定、註冊場景
│  ├─ scenes/               # Boot, Title, Game, Result
│  ├─ objects/              # Passenger, Carriage, Door, Platform
│  ├─ systems/              # Scoring, StationFlow, Satisfaction
│  ├─ data/
│  │  ├─ passengers.json    # 各類乘客參數
│  │  └─ route.json         # 站名與每站難度
│  └─ ui/                   # HUD、按鈕、計時條
├─ raw-assets/               # 本機原始圖，不入庫
├─ CLAUDE.md
└─ .github/workflows/deploy.yml
```

**資料設計要點**：乘客的體積、重量、壓力上限、可互動動作全部寫在 `passengers.json`，站點的人數、開門秒數、下車比例寫在 `route.json`。調難度只改 JSON，不用動程式。

## GitHub Pages 部署流程

用 GitHub Actions 在每次 push 到 `main` 時自動 build 並部署，網址會是 `https://<你的帳號>.github.io/mrt-squeeze/`。

1. 建立公開 repo `mrt-squeeze`（免費帳號的 Pages 需要公開 repo）
2. `vite.config.ts` 設 `base: '/mrt-squeeze/'`，否則部署後圖片與 JS 會 404
3. 程式裡載入資源一律用相對路徑或 `import.meta.env.BASE_URL`，不要寫死 `/assets/...`
4. Repo 的 Settings → Pages → Source 選「GitHub Actions」
5. 加入下方 workflow，push 後到 Actions 分頁看部署結果

```yaml
# .github/workflows/deploy.yml（action 版本號請以當下最新版為準）
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: true
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

之後想用自己的網域，在 Pages 設定填自訂網域，並把 `base` 改回 `'/'`。
